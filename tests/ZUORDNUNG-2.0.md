# Zuordnung alt → neu (Version 1.3 → 2.0, geführte Bedienung)

Phase 0: Jedes Bedienelement, jede Meldung, jeder Hinweis und jede Sperre der Version 1.3 mit ihrem neuen Platz.

**Bildschirme in 2.0:**

| Kürzel | Bildschirm |
|---|---|
| **S** | Start |
| **A1** | Datei |
| **A2** | Prüfen |
| **A3** | Speichern |
| **R1** | Zurückbauen: Dateien |
| **R2** | Zurückbauen: Prüfen |
| **R3** | Zurückbauen: Speichern |

**Immer sichtbar:** **K** = Kopfzeile, **F** = Fußzeile.

## Sperren und Bestätigungen

| # | Alt (1.3) | Neu (2.0) |
|---|---|---|
| S1 | Export blockiert, solange ein Datei-Hinweis nicht abgehakt ist | A3: jeder Hinweis eine Ampel-Zeile mit Abhaken; Speichern blockiert, bis alle abgehakt sind (alle Wege) |
| S2 | Schlusscheck-Fund blockiert bis „bewusst stehen lassen“ abgehakt | A3 Ampel-Zeile „Schlusscheck“; Speichern blockiert wie bisher (alle Wege) |
| S3 | Rückbaufähig: Warnung „Schlüsseldatei noch nicht gespeichert“ nach dem Export | A3: verschärft. „2 Datei speichern“ ist erst aktiv, wenn der Schlüssel zum aktuellen Stand gespeichert ist; nach jeder Änderung der Treffer erneut |
| S4 | Rückbau: falsche Schlüsseldatei (kein Platzhalter gefunden) → nichts wird erzeugt | R2 rote Zeile; „Weiter“ gesperrt |
| S5 | Rückbau: Abweichungen → Bestätigung vor dem Speichern | R2 Bestätigung (Weiter erst danach); beim Speichern erneut geprüft |
| S6 | Rückbau: Platzhalter noch im Ergebnis → Speichern blockiert bis Abhaken | R3 Ampel mit Abhaken |
| S7 | Bestätigungsdialoge (siehe E70) | unverändert |
| S8 | Rückbau nur mit beiden Dateien | R1 „Weiter“ erst aktiv mit beiden |
| S9 | Export nur mit geladenem Dokument | A1 „Weiter“ erst mit Antwort und Datei/Text |
| S10 | (neu) offene Fragen | A3: Speichern erst nach ausdrücklicher Bestätigung |
